# Utsav Kumar Garg — Portfolio

Personal portfolio (dark theme) with pages:
- Home (index.html)
- About (about.html)
- Projects (projects.html)
- Contact (contact.html)
- Sign-Up / Login demo (auth.html)

## Run locally
1. Place Me.jpg inside images/.
2. Open the portfolio folder in VS Code.
3. Right-click index.html → Open with Live Server (recommended) OR open index.html in your browser.

## Notes
- Sign-up/login and contact are client-side simulations (no backend).
- Edit projects.html to add real project links/descriptions.
